#                duplicate   - superseded by a manifest-tracked skill that is installed

#                extension   - provisioned by a VS Code extension / CLI, never by this bundle
#
# Why this file exists: until 2026-11-02 the on-disk count was explained only in README prose,
# so nothing failed when a new orphan appeared. `check-bundle-integrity.ps1` now asserts that
# every directory in ~/.agents/skills/ is either a manifest row, a VS Code extension skill, or a
# row in THIS file. Adding a skill to the bundle without a manifest row fails the gate instead of
# silently skewing the documented count.
#
# AUDIT 2026-11-19: this file claimed 39 skills. **38 were no longer on disk** - the whole
# `sp-*` and `po-*` Copilot-adaptation set, the six `gstack-*`, both `gbrain-*`,
# `headroom-workflow`, the three research ports and `huashu-design` had all been cleared, but the
# allowlist was never pruned, so the gate reported 38 permanent "stale allowlist entry" FAILs.
# Two entries also became wrong for a different reason: `sp-brainstorm` and `sp-verify` were
# hand-ports BECAUSE `brainstorming` was gate-blocked and `verification-before-completion` had no
# row. On 2026-11-19 `brainstorming` was adopted under a reviewed baseline and
# `verification-before-completion` was confirmed installed and tracked in the README - so both are
# now real skills and must NOT be allowlisted here.
#
# RULE: a row here must correspond to a directory that actually exists. When a skill is removed
# or adopted as a manifest row, delete its row here in the same change.
